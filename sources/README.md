# Source handling

The registry is authoritative for source rights/status.

## Storage rules
- Public-domain or explicitly licensed material may be stored locally when useful.
- Copyrighted reference material should not be bulk copied into this repository without permission.
- A source URL existing on the web does not itself prove redistribution rights.
- Modern translations require their own rights review even when the original ancient text is public domain.
- `rights_review_required` means research may identify/select an edition, but bulk ingestion must wait until rights are understood.
- `do_not_ingest` sources must never be copied into the corpus.

## Extraction
Agents may use accessible source material to create original, atomic rule summaries with precise provenance. They must not reproduce substantial copyrighted passages.
