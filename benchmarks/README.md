# Benchmarks

Benchmarks will test deterministic calculations and interpretation plumbing.

Planned fixtures:
- timezone and DST resolution,
- tropical planetary longitudes,
- sidereal longitudes by explicit ayanamsha,
- houses and angles,
- aspects and orbs,
- nakshatras and padas,
- divisional charts,
- dashas,
- numerology reductions,
- Human Design mechanical calculations,
- end-to-end traceability from raw input to user-facing claim.

Benchmark fixtures must state the reference calculator/source and accepted tolerance.
